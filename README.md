# Bohlins Maskiner rekryteringssida

Landningssida för rekryteringskampanj: **Logistik och lageradministratör** till Bohlins Maskiner i Sollentuna.

## Utveckling

```bash
npm install
npm run dev
```

Öppna [http://localhost:3011](http://localhost:3011).

## Stack

- Next.js 15.5 (App Router, Turbopack)
- React 19
- Tailwind CSS v4
- TypeScript
- Nunito Sans (Google Fonts)
